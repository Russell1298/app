Section 3
Scope & Methodology
What was tested, how, and what is out of scope
This assessment is fully passive and non-invasive. No traffic was generated beyond what a normal browser visit produces, no authentication was attempted, and no exploit code was run. All findings are based on publicly observable information.
Target Scope
{% if result.scan_id %}{% endif %}
ItemValue
Primary domain{{ result.domain }}
Scan date{{ scan_date }}
ProtocolHTTPS (HTTP fallback where applicable)
Report ID{{ result.scan_id }}
Modules Run
Security Headers
Checks HTTP response headers for missing or misconfigured security controls (CSP, HSTS, X-Frame-Options, etc.).
DNS & Email
Analyses DNS records for SPF, DMARC, DNSSEC, CAA, and other email authentication controls.
SSL / TLS
Evaluates the certificate chain, expiry, supported TLS versions, and self-signed status.
Public Exposure
Passively probes for commonly exposed sensitive paths (.git, .env, admin panels, debug endpoints).
Subdomain Discovery
Queries the public certificate transparency log (crt.sh) for known subdomains and verifies DNS resolution.
Secret Exposure
Scans the homepage HTML and linked JavaScript files for accidentally published credentials and API keys.
Fingerprinting
Identifies the server software, CMS, frameworks, and CDN from headers, cookies, and page content.
Out of Scope
This report does not include: authenticated scanning, brute-force attempts, exploit testing, social engineering, physical security, internal network assessment, or manual code review. For a full penetration test, contact a certified security professional.
